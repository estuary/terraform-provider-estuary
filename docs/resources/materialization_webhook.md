# estuary_materialization_webhook (Resource)

Sends the documents of Estuary collections to an HTTP endpoint of your server.

See the [Bindings](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/bindings), [Backfills](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/backfills) and [Secrets](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/secrets) guides for how the provider manages them.

## Example Usage

```terraform
variable "webhook_token" {
  type      = string
  sensitive = true
}

# HTTPS endpoint authenticated by a Bearer token header.
resource "estuary_materialization_webhook" "orders" {
  name = "hooks/orders"

  config = {
    address = "https://hooks.example.com/estuary/"

    headers = {
      custom_headers = [
        { name = "Authorization", value = "Bearer ${var.webhook_token}" },
        { name = "X-Source", value = "estuary" },
      ]
    }
  }

  bindings = [
    {
      source   = "acmeCo/mongodb/shop/orders"
      resource = { relative_path = "orders" }
    },
    {
      source   = "acmeCo/mongodb/shop/customers"
      resource = { relative_path = "crm/customers" }

      fields = {
        recommended = "1"
        require     = ["flow_document"]
      }
    },
  ]
}

# Every collection of a capture, sent to an internal server from 2026 on.
resource "estuary_materialization_webhook" "events" {
  name = "hooks/events"

  source = {
    capture = "acmeCo/aurora/source-amazon-aurora-postgres"
  }

  config = {
    address = "https://123.4.567.89:3000/webhook/"
  }

  bindings = [
    {
      source     = "acmeCo/aurora/public/events"
      not_before = "2026-01-01T00:00:00Z"
      resource   = { relative_path = "events" }
    },
  ]
}
```

- `on_incompatible_schema_change` (String) What an automated change, such as a capture discovery, does when it's incompatible with a materialized table: 'backfill' (default) backfills the affected bindings, 'disableBinding' disables them, 'disableTask' disables the materialization, and 'abort' stops the automated change. - `catalog_name` (String) Catalog name the materialization was created or imported under, with the tenant and connector name.
