Manage [Estuary](https://estuary.dev) captures (sources) and materializations (destinations) as code.

## Documentation

The provider documentation is on the [Terraform Registry](https://registry.terraform.io/providers/estuary/estuary/latest/docs): provider configuration, every resource and data source, and guides. Start with [Getting Started](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/getting-started).

## Quick Start

Requires Terraform 1.11 or later and [`flowctl`](https://docs.estuary.dev/concepts/flowctl/) where Terraform runs.

```hcl
terraform {
  required_providers {
    estuary = {
      source  = "estuary/estuary"
      version = "~> 0.1"
    }
  }
}

provider "estuary" {
  tenant = "acmeCo/" # the token comes from FLOW_AUTH_TOKEN
}
```

## Writing Documentation

The documentation comes from three places:

| Source | Becomes |
|---|---|
| `internal/resources/<connector>/README.md` | The connector's page on [docs.estuary.dev](https://docs.estuary.dev) |
| Schema descriptions, `examples/` and `templates/` | The Registry pages under `docs/`, generated by [`tfplugindocs`](https://github.com/hashicorp/terraform-plugin-docs) |
| `templates/guides/` | The Registry guides under `docs/guides/` |

Attribute descriptions live in the connector spec's `description` tags and in the connector README's tables, so change both together. Never edit `docs/` by hand: regenerate it.
