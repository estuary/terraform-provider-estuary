# estuary_source_apple_app_store (Resource)

Captures the customer reviews and analytics reports of App Store apps into Estuary collections, through the App Store Connect API.

See the [Bindings](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/bindings), [Backfills](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/backfills) and [Secrets](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/secrets) guides for how the provider manages them.

## Example Usage

```terraform
variable "app_store_private_key" {
  type      = string
  sensitive = true
}

variable "app_store_key_id" {
  type      = string
  sensitive = true
}

variable "app_store_issuer_id" {
  type      = string
  sensitive = true
}

# The customer reviews of two apps, with auto discovery adding every other stream.
resource "estuary_source_apple_app_store" "apps" {
  name = "apps"

  auto_discover = {
    add_new_bindings                = true
    evolve_incompatible_collections = true
  }

  config = {
    app_ids = ["1234567890", "9876543210"]

    credentials = {
      credentials_title = "Private App Credentials"
      private_key       = var.app_store_private_key
      key_id            = var.app_store_key_id
      issuer_id         = var.app_store_issuer_id
    }
  }

  bindings = [
    {
      resource = {
        name     = "app_reviews"
        interval = "PT1H"
      }
    },
  ]
}
```

### Nested Schema for `backfill`
