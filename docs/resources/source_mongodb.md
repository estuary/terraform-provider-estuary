# estuary_source_mongodb (Resource)

Captures MongoDB collections into Estuary collections, through change streams or batch polling.

See the [Bindings](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/bindings), [Backfills](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/backfills) and [Secrets](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/secrets) guides for how the provider manages them.

## Example Usage

```terraform
variable "mongodb_password" {
  type      = string
  sensitive = true
}

variable "ssh_private_key" {
  type      = string
  sensitive = true
}

# Change stream capture with automatic discovery.
resource "estuary_source_mongodb" "shop" {
  name = "mongodb"

  auto_discover = {
    add_new_bindings                = true
    evolve_incompatible_collections = true
  }

  config = {
    address  = "mongodb+srv://cluster0.123456789.mongodb.net?authSource=admin"
    user     = "flow_capture"
    password = var.mongodb_password
    database = "shop"
  }

  bindings = [
    {
      resource = {
        database   = "shop"
        collection = "users"
      }
    },
    {
      resource = {
        database   = "shop"
        collection = "orders"
      }
      target = "acmeCo/shop/orders"
    },
  ]
}

# Batch capture of a view and a time series collection.
resource "estuary_source_mongodb" "metrics" {
  name = "mongodb/metrics"

  config = {
    address                 = "mongodb://123.4.567.89:27017?authSource=admin"
    user                    = "flow_capture"
    password                = var.mongodb_password
    database                = "shop,metrics"
    batch_and_change_stream = true
    poll_schedule           = "6h"
  }

  bindings = [
    {
      resource = {
        database      = "shop"
        collection    = "user_view"
        capture_mode  = "Batch Snapshot"
        cursor_field  = "_id"
        poll_schedule = "1h"
      }
    },
    {
      resource = {
        database      = "metrics"
        collection    = "readings"
        capture_mode  = "Batch Incremental"
        cursor_field  = "ts"
        poll_schedule = "daily at 02:00Z"
      }
    },
    {
      resource = {
        database     = "shop"
        collection   = "events"
        capture_mode = "Change Stream Incremental"
      }
    },
  ]
}

# SSH tunnel with advanced change stream options.
resource "estuary_source_mongodb" "private" {
  name = "mongodb/private"

  config = {
    address  = "mongodb://123.4.567.89:27017?authSource=admin"
    user     = "flow_capture"
    password = var.mongodb_password

    network_tunnel = {
      ssh_forwarding = {
        ssh_endpoint = "ssh://ec2-user@ec2-123-4-567-89.compute-1.amazonaws.com:22"
        private_key  = var.ssh_private_key
      }
    }

    advanced = {
      max_await_time      = "10s"
      disable_pre_images  = true
      exclude_collections = "shop:sessions,shop:carts"
      skip_backfills      = "shop:events"
    }
  }

  bindings = [
    {
      resource = {
        database   = "shop"
        collection = "events"
      }
    },
  ]
}
```

- `keep_unmanaged_bindings` (Boolean) Keeps the live bindings the configuration doesn't declare, such as those Estuary or the dashboard adds, untouched. False manages every binding, removing undeclared ones, and conflicts with auto_discover. Defaults to true. A provider control Estuary never sees.

### Read-Only

- `catalog_name` (String) Catalog name the capture was created or imported under, with the tenant and connector name. Refreshes and deletions address it, so a provider tenant change replaces the capture under the new tenant, with a plan warning, instead of managing whatever entry has its name there.

<a id="nestedatt--bindings--backfill"></a>
### Nested Schema for `bindings.backfill`

Optional:

- `strategy` (String) Overrides the backfill.strategy of the capture for this binding: 'incremental' or 'dataflowReset'. Changing it alone publishes nothing.
- `trigger` (Number) Set or raise it to backfill the binding: capture the whole resource again. A provider control Estuary never sees, not its backfill counter: each set or raise adds one to the live counter, or resets the collection with 'dataflowReset', leaving the counter as is. Setting it when the binding or the capture is added, or in the first apply after an import, backfills nothing. At least 1, can't be lowered, and can't be set or raised on a disabled binding.



<a id="nestedatt--config"></a>
### Nested Schema for `config`

Required:

- `address` (String) Connection URI of the deployment, holding only the host and connection options (e.g., 'mongodb+srv://cluster0.123456789.mongodb.net?authSource=admin'). A mongodb:// host can include its port, a mongodb+srv:// host can't. The plan rejects credentials in it, such as user:password@ or a password option, as state and logs would hold them in plain text: set them in user and password. Credentials found in the live value show as ***.
- `password` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Password of the database user. Write-only.
- `user` (String) Database user to connect as.

Optional:

- `advanced` (Attributes) Options for advanced users, rarely needed. (see [below for nested schema](#nestedatt--config--advanced))
- `batch_and_change_stream` (Boolean) Also discovers the collections that can only be batch captured, such as views and time series collections, when the deployment supports change streams. Every collection is batch captured when the deployment doesn't support change streams.
- `database` (String) Comma-separated list of databases to discover. If unset, every available database is discovered.
- `network_tunnel` (Attributes) Connects through an SSH server acting as a bastion host. (see [below for nested schema](#nestedatt--config--network_tunnel))
- `poll_schedule` (String) Default polling schedule of batch collections: a Go duration such as '5m' or '6h', or a daily time in UTC such as 'daily at 12:34Z'. Defaults to '24h'.

Read-Only:

- `password_hash` (String, Sensitive) Salted hash of password, detecting its changes without storing it.

<a id="nestedatt--config--advanced"></a>
### Nested Schema for `config.advanced`

Optional:

- `disable_pre_images` (Boolean) Stops requesting pre-images, even when the deployment supports them and they are enabled for the collections.
- `exclude_collections` (String) Comma-separated list of collections to exclude from the database change streams, each formatted as database:collection. Cannot be set with exclusive_collection_filter, nor list a collection with an enabled binding.
- `exclusive_collection_filter` (Boolean) Adds a pipeline filter to the database change streams so they only match events of enabled bindings. Use it only with a small number of bindings. Cannot be set with exclude_collections.
- `max_await_time` (String) Maximum time to wait for new change stream events before returning an empty batch, as a Go duration such as '10s'. Defaults to '1s'.
- `skip_backfills` (String) Comma-separated list of collections not to backfill, each formatted as database:collection. Use *:* to skip the backfill of every change stream collection. Only applies to Change Stream Incremental bindings: naming another binding fails validation, while *:* skips only the change stream ones.

### Nested Schema for `auto_discover`

Optional:

- `add_new_bindings` (Boolean) Adds a binding for each resource discovery finds in the source that isn't declared, when the capture is created and on each later discovery. Terraform doesn't manage those bindings; declare a binding to manage it.
- `evolve_incompatible_collections` (Boolean) Automatically updates the target collections when the source schema changes in a way they can't accept.


<a id="nestedatt--backfill"></a>
### Nested Schema for `backfill`

Optional:

- `strategy` (String) Default backfill strategy of the bindings: 'incremental' (default) captures again into the existing collection, 'dataflowReset' resets the collection, backfilling its materializations and truncating their tables. Changing it alone publishes nothing.
- `trigger` (Number) Set or raise it to backfill every enabled binding of the capture, including those Terraform doesn't manage. A provider control Estuary never sees, not its backfill counter: each set or raise adds one to each binding's live counter, or resets its collection with 'dataflowReset', leaving its counter as is. Setting it when the capture is created, or in the first apply after its import, backfills nothing. At least 1, and can't be lowered.
