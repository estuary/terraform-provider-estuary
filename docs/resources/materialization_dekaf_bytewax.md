# estuary_materialization_dekaf_bytewax (Resource)

Exposes Estuary collections as Kafka topics through Dekaf, for Bytewax to read.

See the [Bindings](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/bindings), [Backfills](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/backfills) and [Secrets](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/secrets) guides for how the provider manages them.

## Example Usage

```terraform
variable "dekaf_token" {
  type      = string
  sensitive = true
}

# Two collections exposed as Kafka topics, the consumer authenticating with the token.
resource "estuary_materialization_dekaf_bytewax" "analytics" {
  name = "analytics"

  config = {
    token              = var.dekaf_token
    strict_topic_names = false
    deletions          = "kafka"
  }

  bindings = [
    {
      source   = "acmeCo/mongodb/shop/orders"
      resource = { topic_name = "orders" }
    },
    {
      source   = "acmeCo/mongodb/shop/users"
      resource = { topic_name = "users" }
    },
  ]
}
```
