# estuary_source_mongodb (Data Source)

Reads every live binding of a capture by name, including those Terraform doesn't manage, such as the ones discovery or the dashboard adds.

Each element of `live_bindings` has the attributes of the resource's `bindings`. See [Every Live Binding](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/bindings#every-live-binding) for when it's read and how to use it.

## Example Usage

```terraform
# Live bindings of a capture managed outside this configuration.
data "estuary_source_mongodb" "source" {
  name = "mongodb"
}
```
