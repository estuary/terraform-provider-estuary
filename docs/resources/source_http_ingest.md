# estuary_source_http_ingest (Resource)

Captures the JSON documents sent to an HTTP endpoint Estuary hosts, such as webhook deliveries, into Estuary collections.

See the [Bindings](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/bindings), [Backfills](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/backfills) and [Secrets](https://registry.terraform.io/providers/estuary/estuary/latest/docs/guides/secrets) guides for how the provider manages them.

## Example Usage

```terraform
variable "webhook_token" {
  type      = string
  sensitive = true
}

variable "zoom_secret_token" {
  type      = string
  sensitive = true
}

variable "webhook_signing_secret" {
  type      = string
  sensitive = true
}

# Two paths behind a bearer token, with the delivery ID of one sender as document ID.
resource "estuary_source_http_ingest" "webhooks" {
  name = "webhooks"

  config = {
    paths                = ["/github", "/vendors/{vendorId}/products"]
    allowed_cors_origins = []
    require_auth_token   = var.webhook_token
  }

  bindings = [
    {
      resource = {
        stream         = "/github"
        path           = "/github"
        id_from_header = "X-GitHub-Delivery"
      }
      target = "acmeCo/webhooks/github"
    },
    {
      resource = {
        stream = "/vendors/{vendorId}/products"
        path   = "/vendors/{vendorId}/products"
      }
      target = "acmeCo/webhooks/vendor-products"
    },
  ]
}

# Verifying the signature of Zoom webhooks.
resource "estuary_source_http_ingest" "zoom" {
  name = "webhooks/zoom"

  config = {
    paths = ["/zoom"]

    signature_config = {
      provider   = "zoom"
      public_key = var.zoom_secret_token
    }
  }

  bindings = [
    {
      resource = {
        stream = "/zoom"
        path   = "/zoom"
      }
      target = "acmeCo/webhooks/zoom"
    },
  ]
}

# Verifying signatures a sender computes its own way, an HMAC of the timestamp and the body.
resource "estuary_source_http_ingest" "signed" {
  name = "webhooks/signed"

  config = {
    paths                = ["/events"]
    allowed_cors_origins = ["https://app.acme.example"]

    signature_config = {
      provider                = "custom"
      algorithm               = "hmac_sha256"
      public_key              = var.webhook_signing_secret
      signature_header        = "X-Signature"
      signature_encoding      = "base64"
      signing_string_template = "{TIMESTAMP}:{PAYLOAD}"
      timestamp_header        = "X-Timestamp"
      max_signature_age       = 120
    }
  }

  bindings = [
    {
      resource = {
        stream = "/events"
        path   = "/events"
      }
      target = "acmeCo/webhooks/events"
    },
  ]
}
```

## Schema

### Required

- `bindings` (Attributes Set) Captured resources, one per binding. Their order doesn't matter, as Estuary identifies a binding by its resource path, so plans show only the bindings added, removed or changed. (see [below for nested schema](#nestedatt--bindings))
- `config` (Attributes) Connection, authentication and capture settings of the source. (see [below for nested schema](#nestedatt--config))
- `name` (String) Catalog name of the capture (e.g., shop). The provider adds the tenant in front and the connector name at the end, unless they're already there. Changing the resulting catalog name, through name or the provider tenant, replaces the capture.

### Optional

- `auto_discover` (Attributes) Periodically checks the source for new resources and schema changes. (see [below for nested schema](#nestedatt--auto_discover))
- `backfill` (Attributes) Backfill control of the whole capture. (see [below for nested schema](#nestedatt--backfill))
- `data_plane` (String) Data plane the capture runs in (e.g., ops/dp/public/example-data-plane), defaulting to the provider data_plane when the capture is created. Estuary can't move a live capture, so setting another data plane than it runs in fails the plan.
- `image` (String) Connector image, defaulting to ghcr.io/estuary/source-http-ingest:v1. Only the tag can change, e.g. ghcr.io/estuary/source-http-ingest:dev.
- `keep_unmanaged_bindings` (Boolean) Keeps the live bindings the configuration doesn't declare, such as those Estuary or the dashboard adds, untouched. False manages every binding, removing undeclared ones, and conflicts with auto_discover. Defaults to true. A provider control Estuary never sees.
- `shards` (Dynamic) Shard settings of the capture, with Estuary keys such as logLevel and disable.

### Read-Only

- `catalog_name` (String) Catalog name the capture was created or imported under, with the tenant and connector name. Refreshes and deletions address it, so a provider tenant change replaces the capture under the new tenant, with a plan warning, instead of managing whatever entry has its name there.

### Nested Schema for `bindings.backfill`

Optional:

- `strategy` (String) Overrides the backfill.strategy of the capture for this binding: 'incremental' or 'dataflowReset'. Changing it alone publishes nothing.
- `trigger` (Number) Set or raise it to backfill the binding: capture the whole resource again. A provider control Estuary never sees, not its backfill counter: each set or raise adds one to the live counter, or resets the collection with 'dataflowReset', leaving the counter as is. Setting it on a binding Estuary doesn't have yet, when the capture is created, or in the first apply after an import, backfills nothing, while setting it on an existing binding Terraform takes over backfills it. At least 1, can't be lowered, and can't be set or raised on a disabled binding.

### Nested Schema for `config`

Optional:

- `allowed_cors_origins` (List of String) Request origins allowed through the Access-Control-Allow-Origin header. An empty list disables CORS. It can't hold '*' with require_auth_token. Unset, the connector's own default is ['*'], which allows every origin.
- `paths` (List of String) URL paths the capture accepts requests at, each starting with / (e.g., '/orders'). Discovery lists one binding per path. A path can have parameters, as in OpenAPI path templating (e.g., '/vendors/{vendorId}/products'), which are captured under _meta/pathParams. Unset, the connector's own default is ['/webhook-data'].
- `require_auth_token` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Bearer token every request must send in its Authorization header. Unset, anyone who knows the URL of the capture can write to its collections. Write-only.
- `signature_config` (Attributes) Verifies the signature of each request, rejecting the unsigned and wrongly signed ones. (see [below for nested schema](#nestedatt--config--signature_config))

Read-Only:

- `require_auth_token_hash` (String, Sensitive) Salted hash of require_auth_token, detecting its changes without storing it.

<a id="nestedatt--config--signature_config"></a>
### Nested Schema for `config.signature_config`

Required:

- `provider` (String) Sender whose signatures are verified: 'none' verifies nothing, 'twilio' (Twilio SendGrid), 'zoom' and 'knock' verify theirs with public_key, and 'custom' verifies the signature the other attributes describe. Only the attributes of the selected provider are used.

Optional:

- `algorithm` (String) Signature algorithm, required with 'custom': 'hmac_sha256' or 'ecdsa'.
- `max_signature_age` (Number) Seconds after which a signed request is rejected, from 1 to 259200. With 'custom', it only applies when timestamp_header is set. Defaults to 300.
- `public_key` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Key the signatures are verified with, required by every provider but 'none': the PEM-encoded ECDSA public key of the Twilio SendGrid event webhook, the Zoom webhook secret token, the Knock signing key, or with 'custom' the PEM-encoded public key for 'ecdsa' or the shared secret for 'hmac_sha256'. Write-only.
- `signature_encoding` (String) Encoding of the signature in its header, with 'custom': 'hex' (default) or 'base64'.
- `signature_header` (String) HTTP header holding the signature, required with 'custom'.
- `signing_string_template` (String) Template of the string that is signed, required with 'custom'. It must include {PAYLOAD} and may include {TIMESTAMP} (e.g., '{TIMESTAMP}:{PAYLOAD}').
- `timestamp_header` (String) HTTP header holding the timestamp of the request, with 'custom'.

Read-Only:

- `public_key_hash` (String, Sensitive) Salted hash of public_key, detecting its changes without storing it.



<a id="nestedatt--auto_discover"></a>
### Nested Schema for `auto_discover`

Optional:

- `add_new_bindings` (Boolean) Adds a binding for each resource discovery finds in the source that isn't declared, when the capture is created and on each later discovery. Terraform doesn't manage those bindings; declare a binding to manage it.
- `evolve_incompatible_collections` (Boolean) Automatically updates the target collections when the source schema changes in a way they can't accept.


<a id="nestedatt--backfill"></a>
### Nested Schema for `backfill`

Optional:

- `strategy` (String) Default backfill strategy of the bindings: 'incremental' (default) captures again into the existing collection, 'dataflowReset' resets the collection, backfilling its materializations and truncating their tables. Changing it alone publishes nothing.
- `trigger` (Number) Set or raise it to backfill every enabled binding of the capture, including those Terraform doesn't manage. A provider control Estuary never sees, not its backfill counter: each set or raise adds one to each binding's live counter, or resets its collection with 'dataflowReset', leaving its counter as is. Setting it when the capture is created, or in the first apply after its import, backfills nothing. At least 1, and can't be lowered.
